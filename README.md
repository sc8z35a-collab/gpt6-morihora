# HOLLOW WOODS — 森は、見ている。

スマートフォンとPCのブラウザーで遊べる、一人称3Dサバイバルホラー。約174m四方の自動生成される森で3種類の怪異から逃げ、10個のパイを集めて北側の鳥居へ到達するとクリアします。

## 現在完成している機能

- Three.jsによるリアルタイム3D描画。森、岩、パイ、鳥居、怪異はコードで生成。
- 29×29セル、1セル6mの迷路。複数の迂回路を設け、全通路・収集物・出口の到達可能性を検証。
- 巨大な顔、浮遊する幽霊、異様に背の高いノッポの3種類の追跡者。
- 共有距離マップによる経路探索。幽霊は一定時間ごとに、プレイヤーから離れた接続済みの通路へ再出現。
- パイ10個の自動収集、未収集時の出口拒否、クリア・捕獲・リトライ。
- 探索／標準／悪夢の3難易度。開始直後には短い猶予時間あり。
- スタミナ、ダッシュ、息切れと回復、懐中電灯。
- 探索済み領域を表示する地図、コンパス、収集完了後の鳥居の方向案内。
- 足音、風音、心音、怪異の左右定位音、収集音。Web Audioで生成し、音声ファイルは不要。
- 一時停止、設定画面、結果画面、端末内の難易度別ベストタイム。
- 明るさ、感度、描画品質、自動解像度調整、30／60 FPS上限、恐怖演出軽減。
- スマホの縦向き／横向き用レイアウト、左右同時タッチ操作。
- バックグラウンド移行時の停止、WebGLコンテキスト喪失／復旧への対応。

## 起動方法・機能の入口URI

| URI | 用途 |
|---|---|
| `/` または `/index.html` | タイトル画面。難易度を選び「森に入る」で開始 |
| `/play.html` | `/index.html?play=1` に移動してクイックプレイ |
| `/index.html?play=1` | タイトル操作を省略して開始。音声・マウス捕捉にはユーザー操作が必要 |
| `/index.html?seed=771923` | 指定シードで森を生成。`play=1` と併用可能 |
| `/tests.html` | `/index.html?selftest=1` に移動して自動診断 |
| `/index.html?selftest=1` | 回帰テストを実行。画面に合否を、コンソールに各結果を表示 |
| `/benchmark.html` | 固定シード771923・12視点の描画統計を取得 |
| `/index.html?benchmark=1&seed=771923` | 同じベンチマークの直接入口 |

`seed` は1〜16,777,215の整数。有効な指定がない通常プレイでは毎回ランダム生成します。診断・ベンチマークは現在のプレイを置き換える開発用の入口で、クリア記録を保存しません。

ブラウザーコンソールから以下も参照できます。

```javascript
HollowWoods.diagnostics       // 状態、描画数、解像度、経路探索回数、音声ノード数など
HollowWoods.lastTests         // 実行した回帰テストの結果
HollowWoods.lastBenchmark     // 実行した描画ベンチマークの結果
```

## 操作方法

### スマートフォン

- 左スティック：移動。
- 右側の画面をスワイプ：見回す。
- RUN長押し、または左スティックを外周より大きく倒す：走る。
- ライトボタン：懐中電灯の点灯／消灯。
- 右上の照準形ボタン：地図。Ⅱボタン：一時停止。
- パイに近づく：自動収集。

外周ダッシュは右手で視点を操作したまま使用できます。地図を開いてもゲームは進行します。休憩には一時停止を使ってください。

### PC

- WASD／矢印キー：移動。
- マウス：視点。ゲーム画面をクリックするとマウスを捕捉します。
- マウス捕捉が利用できない環境ではドラッグで見回せます。
- Shift：ダッシュ。F：ライト。M：地図。Esc／P：一時停止。

音声は初期状態でOFFです。タイトル右上、または設定でONにしてください。イヤホン推奨。捕獲時の接写などが苦手な場合は「恐怖演出を抑える」を有効にしてください。

## 実施した最適化・修正

### 描画

- 全フィールドを一括描画していた構成を24m単位のセクターに分割。
- 静的な木・茂み・岩・地面・標識を頂点色付きメッシュにまとめ、視野・距離で描画を省略。
- 怪異やパイの剛体パーツを材質ごとに結合。
- 静的メッシュのローカル行列の毎フレーム再計算を停止。
- 遠方の怪異・パイを非表示にし、見えていないパイの見た目の更新を省略。
- 結合メッシュの法線を正規化Int16、頂点色を正規化Uint16に格納。位置はFloat32を維持。
- 標準／高画質の描画解像度上限、負荷に応じた自動解像度調整を実装。
- タイトル背景は最大30 FPS。停止画面・結果画面は変更が必要なときだけ再描画。
- 軽量設定では画面全体の粒子ノイズ合成を省略。

**注意：** セクター結合は描画負荷を下げる一方、元の共有ジオメトリ構成より生成バッファの数・容量が増えるトレードオフがあります。全体のメモリ使用量が減少したという意味ではありません。

### ゲーム処理・AI・UI

- 1/60秒固定刻みのシミュレーションに変更。20／30／60／120 FPSで同じ進行速度になることをテスト。
- 長い処理停止後は最大6ステップまでに制限し、復帰直後の暴走を防止。
- 隣接セル・セル座標を事前計算し、経路探索キューと距離バッファを再利用。
- プレイヤーが別セルに移動したときだけ共有経路マップを再計算。
- 視線判定をグリッドDDAに変更。角のすり抜けを防ぐ判定と、怪異の幅を考慮した直進判定を追加。
- DOM参照をキャッシュ。変更のない文字列の書き換えを省略。
- HUDを約10Hzで更新。スタミナ表示は幅変更ではなくtransformで更新。
- 地図の背景をキャッシュし、探索範囲・収集状態が変化したときだけ再構築。
- 設定変更時の不要な描画バッファリサイズを抑制。

### 入力・状態・音響・後処理

- スティックのデッドゾーンを修正し、微小入力による意図しない移動を防止。
- 外周ダッシュにヒステリシスを追加し、境界での切り替わりを抑制。
- 左右タッチとRUNボタンのpointer IDを別管理。
- タッチキャンセル、停止、地図表示時に入力とpointer captureを解除。
- 地図表示ではPCのマウス捕捉を解除し、意図しない一時停止を防止。
- 一時停止中はゲーム時間だけでなく通知の残り時間も停止。
- 再開時の時間差・シミュレーション残量をリセット。
- リトライ時の走行状態・視野角・各種表示をリセット。
- 壊れたlocalStorage設定を検証し、安全な既定値に復帰。
- 音響処理を独立モジュール化。終了した音のノードをdisconnectし、同時発音数を制限。
- 音声OFFでは不要なAudioContextの生成・稼働を抑制。
- 怪異の音の左右定位を、プレイヤーの向きを基準に修正。
- タイトルへ戻る際に生成ジオメトリ・スプライト材質をdispose。
- WebGL復旧後は画面を再描画し、プレイは明示的な再開操作を待つ。

## 性能測定結果

同一シード **771923**、同一の12視点、デスクトップ用ヘッドレスブラウザーで、Three.jsの描画統計を比較しました。

| 指標 | 最適化前 | 最適化後 | 変化 |
|---|---:|---:|---:|
| 平均描画命令数 | 40 | 20 | 50%減 |
| 平均描画三角形数 | 126,345 | 25,087 | 約80.1%減 |
| 最大描画三角形数 | 136,164 | 47,466 | 約65.1%減 |

最終版でも同じ結果を再確認しています。この値は描画仕事量の比較であり、実機FPSの向上率やバッテリー消費の改善率ではありません。実機GPU・端末温度・ブラウザーで結果は変わります。

### テスト結果

- PC環境：**42項目合格**。
- モバイルエミュレーション：**48項目合格**。
- 100シードの全通路・出口の接続性。
- 10個のパイの一意性・到達性・二重収集防止・出口条件。
- キーボードイベント、視点操作、デッドゾーン。
- 左右同時タッチ、外周ダッシュ、キャンセル時の入力独立性、UIのヒット領域。
- スタミナ消費・回復・息切れ、停止・再開、通知時間の停止。
- 継続的な追跡での経路進行と壁内侵入防止。
- 生成ジオメトリの破棄、3回の再生成・終了での破棄通知。
- 最適化後のタイトル／プレイ画面をPC幅・スマホ幅で確認。

ブラウザーのコンソールでアプリケーションエラーは検出されていません。Three.js旧配布形式の非推奨警告、およびヘッドレス環境のソフトウェアWebGL警告は出る場合があります。

## データモデル・保存先

サーバー・データベース・Table APIは使用していません。

- 森：`Uint8Array` の壁／通路グリッド。
- 探索済み領域：`Uint8Array`。プレイ中のメモリのみ。
- 経路情報：共有 `Int16Array` 距離マップと探索キュー。
- プレイヤー：座標・視点・スタミナ・移動状態。
- パイ：セル番号・座標・収集状態・3Dオブジェクト。
- 怪異：種類・座標・目標セル・速度・再出現時刻。
- 設定：localStorageの `hollow-woods-v1`。
- 難易度別ベストタイム：localStorageの `hollow-woods-records`。

端末・ブラウザー間の同期はありません。localStorageが利用できなくてもゲームはプレイ可能です。ゲーム途中の保存はありません。
